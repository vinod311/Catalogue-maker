PERFUME CATALOGUE APP
=====================
PUBLISH ON GITHUB (free):
1. Extract this zip.
2. github.com > New repository (e.g. "catalogue") > Create.
3. "Add file" > "Upload files" > drag ALL extracted files and the images folder > Commit.
4. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
5. After 1-2 minutes your link is: https://YOUR-USERNAME.github.io/catalogue/
   Send this link (or put it in WhatsApp) to customers.

CHANGE YOUR DETAILS / PRODUCTS:
- Open data.js on GitHub > pencil icon > edit > Commit. Site updates in a minute.
- Set your WhatsApp number in CONFIG (country code + number, no + sign).
- To add a product: copy one { ... } block, paste below it, change id to a new number.
- Photos: upload into the images folder, then write image: "filename.jpg".
