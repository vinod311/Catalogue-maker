CATALOG MAKER - APP FILES

WHAT IS INSIDE
index.html  = the complete catalogue maker (one file, nothing else needed)

HOW TO TEST FIRST (2 minutes)
1. Extract this zip.
2. Open index.html in Chrome on your phone or computer.
3. Add a shop name, WhatsApp number and items, then tap "Download PDF".

HOW TO TURN IT INTO AN APP
1. Use any free "website / HTML to APK" app builder.
2. Upload this zip (or index.html) when it asks for your files.
3. Download the APK and install it on your phone.

GOOD TO KNOW
- It needs internet the first time, because the font and the PDF tool load online.
- Photos: the "Photo" button opens the phone gallery in Chrome.
- Some app builders block file downloads inside the app. If the PDF does not save,
  test in Chrome first, then try another builder.
- Items and shop details are saved on the phone only.
